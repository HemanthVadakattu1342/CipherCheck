# CipherCheck 🔐

CipherCheck is a web-based password strength analyzer designed to help users evaluate the security strength of their passwords using multiple validation criteria.

## 🚀 Features

- Password strength evaluation
- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Provides a strength assessment based on multiple criteria
- Interactive web interface
- Flask-based backend

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## 📌 How It Works

CipherCheck analyzes the password entered by the user against multiple security criteria.

The application evaluates characteristics such as:

- Password length
- Character variety
- Uppercase and lowercase characters
- Numbers
- Special characters

Based on the checks performed, the application provides an indication of the password's overall strength.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/HemanthVadakattu1342/CipherCheck.git
```

### 2. Navigate to the project directory

```bash
cd CipherCheck
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open the local URL shown by Flask in your browser.

## 🖥️ Usage

1. Open the CipherCheck web application.
2. Enter a password in the input field.
3. The application evaluates the password against the implemented security criteria.
4. Review the resulting password-strength assessment.

## 🔒 Security Note

CipherCheck is an educational project designed to demonstrate password-strength evaluation concepts.

Do not enter real passwords or sensitive credentials into publicly hosted or shared versions of this application.
